网站服务器国旗（Server Flag）

一款极简、纯中文界面的Chrome/Edge浏览器扩展程序。浏览任意网站时，浏览器工具栏上的插件图标会自动切换为当前网站服务器所在国家或地区的满格高清国旗；点击图标即可一键查看该网站的CNAME别名、IPv4地址(A记录)、IPv6地址(AAAA记录)及运营商归属地信息。

适合站长、VPS玩家以及日常想快速辨别网站服务器位置的用户，无需打开命令行或第三方站长工具。

主要功能

满格高清国旗图标：内置66个常见国家/地区的高清PNG国旗图标，100%铺满工具栏图标区域，解决Windows系统无法显示国旗Emoji的问题；遇到极冷门地区自动绘制地区代码图标兜底。

一键查看服务器详情：点击国旗图标弹出中文面板，清晰展示当前域名、服务器归属地（国家/地区与城市）、CNAME别名记录、全部IPv4与IPv6地址以及运营商/ASN信息。

一键复制与手动刷新：每条IP均支持一键复制，支持点击“刷新”绕过10分钟本地缓存强制重新解析。

国内外网络自动切换：DNS解析优先使用阿里DNS(DoH)，异常时自动切换腾讯DNSPod与Cloudflare DNS；IP归属地优先使用IP.SB，https://www.google.com/search?q=%E5%A4%87%E7%94%A8ipwho.is%E4%B8%8Eipapi.co，直连和代理环境均可稳定使用。

识别实际连接IP：非代理直连时自动捕获浏览器实际连接的服务器公网IP，并在弹窗中标注“当前连接”。

安装方法（Chrome/Edge通用）

前往本仓库右侧的Releases发布页下载最新版本的压缩包（例如网站服务器国旗插件_v1.0.1.zip），或点击右上角绿色Code按钮选择Download ZIP下载源码。

将压缩包解压到一个平时不会误删的固定文件夹中。

打开浏览器，在地址栏输入以下地址并回车：

Chrome浏览器：chrome://extensions/

Edge浏览器：edge://extensions/

打开页面右上角的开发者模式开关。

点击左上角的加载已解压的扩展程序，选择刚才解压出来的插件文件夹（包含manifest.json的目录）即可完成安装。

点击浏览器右上角的拼图图标，将网站服务器国旗固定到工具栏，刷新任意网页即可看到效果。

常见问题

1. 为什么访问套了Cloudflare等CDN的网站，国旗通常显示为美国？

Cloudflare等大型CDN采用泛播IP（Anycast）技术，全球多个国家的机房共用同一个IP地址。普通IP归属地数据库一般会将这类泛播IP统一归属到CDN服务商总部所在地（如美国），这并不代表网站真实源站位于美国。点开插件图标查看下方的CNAME别名和运营商信息，即可一眼确认该网站是否接入了CDN。

2. 会收集或上传我的浏览记录吗？

不会。插件基于Manifest V3架构开发，不包含任何统计代码或第三方追踪，仅在需要查询当前标签页网站时，向公开的DoH与IP归属地接口发起域名及IP查询，不保存、不上传用户的个人浏览历史。

目录结构

├── manifest.json       # 插件清单配置（Manifest V3）
├── background.js       # 后台服务：IP捕获、多节点DoH解析、归属地查询与图标切换
├── countries.js        # 国家/地区中文名称映射与内置国旗列表
├── popup.html          # 点击图标后的中文详情弹窗
├── popup.css           # 弹窗样式表
├── popup.js            # 弹窗数据渲染、复制与刷新交互
├── icons/              # 插件默认图标与66个高清国旗PNG资源
└── 安装说明.txt         # 本地离线安装步骤说明
